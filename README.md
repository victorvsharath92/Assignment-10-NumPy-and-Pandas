# Assignment-10-NumPy-and-Pandas
Python DA Assignment 1: Data Analysis using  NumPy and Pandas

1.NumPy Array Operations:
.Creating 1D and 2D arrays.
.Inspecting structural properties (shape, dtype, size).
.Vectorized mathematical transformations (Celsius to Fahrenheit).
.Statistical summaries (max, min, mean).
.Positional slicing and subset extraction.

2.Pandas Series:
.Instantiating custom-indexed Series.
.Label-based (.loc) and positional (.iloc) indexing.
.Boolean condition masking.
.Modifying values, dropping elements, and vectorized scalar calculations.

3.Pandas DataFrame:
.Constructing tabular data structures from dictionary records.
.Inspecting schemas, shapes, head/tail records, and types.
.Column projection and multi-condition boolean filtering.
.Categorical distribution (value_counts) and distinct value discovery (unique).
.Group-by aggregation (mean sales by geographical region).
.In-place transformations, column engineering, and targeted row deletions.
